# Nuvexa 🚀

**Nuvexa** is a modern Flutter-based mobile application designed to help users build better habits, manage daily activities, track personal progress, and stay consistent with their goals.

The app combines habit tracking, routines, challenges, progress monitoring, and reminders in one simple and user-friendly experience.

## ✨ Features

* 📊 **Progress Tracking** — Monitor your personal progress over time.
* 🎯 **Challenges** — Create and complete challenges to stay motivated.
* 🔔 **Smart Reminders** — Receive reminders for important activities and challenges.
* 🔥 **Habit Tracking** — Track habits and maintain consistency.
* 📅 **Daily Activities** — Organize and monitor your daily activities.
* 🏆 **Achievements** — Track completed goals and milestones.
* 📈 **Statistics** — View your progress and activity information.
* 🌙 **Modern Dark UI** — Clean and comfortable interface designed for everyday use.
* 💾 **Local Data Storage** — Store application data locally on the device.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Flutter SDK
* Dart SDK
* Android Studio
* Android SDK
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/RuchiDissa/nuvexa.git
```

Navigate to the project:

```bash
cd nuvexa
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

## 📦 Build for Android

To create a release Android App Bundle:

```bash
flutter build appbundle --release
```

The generated `.aab` file can be found in:

```text
build/app/outputs/bundle/release/
```
